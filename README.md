# Video Games Sales Analysis 🎮

A comprehensive Power BI dashboard project analyzing video game sales trends, performance metrics, and market insights.

## Project Overview

This project provides an in-depth analysis of video game sales data using **Power BI** as the primary analytics tool. The analysis includes data cleaning, transformation, and visualization using DAX queries to uncover key insights about the gaming industry.

## Key Features

- **Interactive Dashboards**: Comprehensive Power BI visualizations for sales trends and performance metrics
- **Data Cleaning**: Thorough data preparation and cleansing processes
- **DAX Queries**: Advanced calculations and measures using Data Analysis Expressions (DAX)
- **Sales Analytics**: Detailed breakdown of video game sales by region, genre, platform, and time periods
- **Market Insights**: Trend analysis and performance indicators for gaming platforms

## Project Files

### 📊 Core Files

1. **Videogames_sales_Analysis.pbip**
   - Main Power BI Project file

   - Detailed analysis report
   - In-depth documentation of findings
